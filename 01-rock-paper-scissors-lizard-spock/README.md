# Rock Paper Scissors Lizard Spock

## Description
A command-line rock-paper-scissors game with the extended "Lizard" and "Spock" rules. The player competes against a computer opponent that picks moves randomly.

## Features
- Single-player mode against a random computer opponent
- Extended rules: Rock, Paper, Scissors, Lizard, Spock
- Live score tracking; first to 7 wins

## How to Run
Compile with: gcc main.c -o main
Then run: ./main

## Concepts
- Random number generation (rand / srand)
- Input handling and buffer clearing
- Control flow and game logic

# Balls and their Admirers

## Description
A graphical simulation of many moving balls. Each ball randomly follows another ball, so they gradually cluster at the same position.

## Features
- 100 balls with random position, velocity, radius, and color
- Each ball follows a randomly assigned leader ball
- Real-time rendering with the raylib library

## How to Run
Compile with: gcc main.c -o main -lraylib
Then run: ./main
Requires the raylib library.

## Concepts
- Structs and pointers
- Motion simulation
- Graphical programming with raylib

## Files
